# Problem Context — tools.scalebrandslab.com

## Who We Are

Scale Brands Lab is a content production agency that converts long-form video content into short-form clips for platforms like YouTube Shorts, Instagram Reels, TikTok, and Facebook. The team operates across multiple client accounts simultaneously, running outreach, production, and delivery workflows every day.

## The Problem

The team at Scale Brands Lab relies heavily on manual, repetitive research and outreach work — finding the right YouTube channels, extracting contact emails, building podcast lead lists, generating client-facing reports, and creating thumbnails. These tasks are time-consuming, error-prone when done by hand, and don't scale as the client base grows.

There is no central place where the team can run these workflows. Work is currently scattered across spreadsheets, ChatGPT sessions, Apify dashboards, and manual browser work. There is no shared visibility into what has been processed, what is pending, or where something stopped.

The core problem is this: **the team is doing work that AI and automation can handle, but they have no structured, internal tooling to run it.** This slows down outreach velocity, introduces inconsistency, and creates a bottleneck where senior team members have to supervise low-value repetitive tasks.

## The Solution

`tools.scalebrandslab.com` is an internal HITL (Human-in-the-Loop) workspace where Scale Brands Lab team members can run AI-assisted workflows directly. Each tool in the platform handles one specific job — from email extraction to PDF report generation — with the human staying in control of inputs, review, and exports.

The platform is not a fully autonomous system. It is a structured interface that removes the manual scaffolding around AI tasks: setting up prompts, managing pagination, tracking what has been processed, and producing clean outputs. The human decides when to run a task and reviews the output before it leaves the platform.

## Goals

- Reduce the time spent on repetitive outreach and research tasks
- Give the team full visibility into batch jobs, progress, and pending work
- Standardise the output format across all tools so results are consistent and exportable
- Allow the team to scale operations without proportionally scaling headcount on manual tasks
- Keep all tooling internal — no dependency on ad-hoc ChatGPT sessions or fragmented external tools

## Users

This platform is used exclusively by the Scale Brands Lab internal team. There are no external users or clients accessing this product. Access is controlled and all users share the same operational context.
